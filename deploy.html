🚀 Sahbi AI Deploy Hub
Prépare un projet pour le publier sans connecter tes comptes

Déployer proprement, sans stocker tes identifiants

Sahbi AI prépare les fichiers et les commandes. Tu choisis ensuite ton hébergeur. Les connexions permanentes aux comptes restent désactivées.

🌍 GitHub Pages

Idéal pour sites statiques.

1. Télécharge le ZIP depuis Builder 2. Mets index.html à la racine d'un repo public 3. Settings → Pages → Deploy from branch → main / root

▲ Vercel

Idéal pour React/Next/Vite.

npm install npm run build vercel --prod

🚂 Railway

Idéal pour API/backend.

Ajoute package.json / Dockerfile Définis PORT Déploie depuis ton repo Ajoute les variables d'environnement dans Railway

☁️ Cloudflare Pages

Idéal pour statique/Vite.

Build command: npm run build Output directory: dist Aucune clé secrète dans le frontend

🛡️ Checklist avant production

□ Pas de secret/API key dans le navigateur □ Validation des entrées □ HTTPS uniquement □ Auth côté serveur pour les actions sensibles □ Limites de débit □ Logs sans données privées □ Sauvegarde de la base □ Tests Build & Test / Autopilot terminés
