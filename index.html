Personnel · privé · sans clé API
Mode gratuit : GitHub Pages héberge seulement l’interface. Le modèle IA est téléchargé par WebLLM depuis son hébergement de modèles puis stocké dans le cache de ton navigateur. Sur mobile, commence par Rapide 1B (~0,9 Go).

Mémoire personnelle

Stockée uniquement dans ce navigateur. Sahbi AI peut aussi lire des fichiers texte, code, CSV/JSON et PDF directement sur ton appareil.

Skills appris

Sahbi AI peut apprendre des procédures et habitudes. Les skills sont déclaratifs : ils n’exécutent jamais de code arbitraire.
