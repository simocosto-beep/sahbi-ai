# License notes

Project code in this folder is intended to be distributable under a permissive license.

The proposed base model is Qwen/Qwen3-8B. Its official Hugging Face model card currently declares Apache-2.0.

Before releasing adapters or merged weights:
1. Re-check the exact base model license and model card.
2. Preserve required notices and attribution.
3. Audit every dataset source for redistribution/training rights.
4. Publish a model card describing the fine-tune, limitations and evaluation.
5. Get legal review before large-scale commercial distribution if needed.

This file is operational guidance, not legal advice.
